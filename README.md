# Build a Bot

A free word game you play in your browser — hangman, made family friendly: guess the word letter by letter, and every miss adds another part to the robot you're building instead of anything grim.

**Live:** https://jesuslovestyler.github.io/Build-a-bot/
**Home:** https://jesuslovestyler.com/

One self-contained page: no account, no ads, nothing to buy. Released into the public domain (Unlicense — see LICENSE). Built by Tyler with Noki.
